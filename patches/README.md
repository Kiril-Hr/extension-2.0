# Historical integration patches

`DEVEX-017-factory-integration.patch` records the original author-factory integration before it was mapped into the public repository layout. It is retained unchanged as diagnostic/release history; the current implementation is already in `devxtension/`.

The patch includes historical workstation paths and refers to the former local directory layout. These are not credentials. Do not apply it blindly to current main or use its old test-environment paths as setup instructions. Its original bytes are preserved so the record remains reproducible; Git history still contains the earlier paths.

For current installation and examples, use the [root README](../README.md).
